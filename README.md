# Personal Skill Retention Tracker

A Django-based web application designed to help users organize their skills, track learning progress, and maintain their knowledge through structured revision and skill retention analytics.

## 📌 Overview

Learning a skill is only the first step. Without regular practice and revision, knowledge can gradually fade.

**Personal Skill Retention Tracker** provides a platform where users can record the skills they are learning, monitor their progress, track retention, and use analytics to understand their learning performance over time.

The project was developed using **Python and Django** as a practical web development project.

## ✨ Features

* 👤 User-based skill tracking
* 📚 Add and manage personal skills
* 📊 Track skill learning progress
* 📈 Skill retention analytics and dashboard
* 📉 Progress visualizations
* 🔄 Record revision and retention activities
* 📝 Maintain skill-related information
* 💾 Database-backed data storage
* 🔐 User authentication and management
* 🖥️ Responsive web interface

## 📊 Skill Retention Analytics

The application provides a dashboard that helps users understand their skill retention and learning progress through visual analytics.

Users can view:

* Overall skill progress
* Skill retention information
* Revision and learning activity
* Progress trends
* Visual representations of tracked skills

These visualizations make it easier to identify skills that may require additional practice or revision.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ananyathakur23/PersonalSkillRetentionTracker.git
```

### 2. Navigate to the project directory

```bash
cd PersonalSkillRetentionTracker
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
venv\Scripts\Activate.ps1
```

**Windows Command Prompt:**

```cmd
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Apply database migrations

```bash
python manage.py migrate
```

### 7. Run the development server

```bash
python manage.py runserver
```

Open the application in your browser:

```text
http://127.0.0.1:8000/
```
